# zySoulbot 管理后台视觉与交互设计规范（DESIGN.md）

> 版本：v1.0 · 2026-11-24
> 视觉定位：**高审美轻二次元（Bright Modern ACG）** —— 清透明亮、有角色陪伴感，但拒绝土味堆砌与廉价“AI 蓝紫渐变”。
> 工艺基准：融合 [zhuiye-theme-preview](../../preview/zhuiye-theme-preview.html) 的三套二次元明快主题气质，以及 Vercel Web Interface Guidelines、Radix 12 阶语义色彩体系、Emil Kowalski 弹簧微交互与 Impeccable 反“AI 味”准则。

---

## 1. 视觉气质定义（什么是好的“二次元管理后台”）

参考优秀二次元游戏官方社区 / 现代 ACG 工具（如原神/星穹铁道米游社卡片体系、蔚蓝档案的通透几何感、Linear/Vercel 级别的排版秩序）：

- **明快通透（Airy & Luminous）**：以高明度浅色柔底为默认主视觉（提供三套角色主题：**须弥薄荷 Mint / 晴空天蓝 Sky / 樱花桃粉 Sakura**，并支持精致的**星夜深色模式 Night**）。
- **克制的二次元识别元素**：
  - **微妙几何装饰**：卡片角落的极细星芒/菱形锚点、细斜切角状态徽章、淡淡的半透明磨砂顶栏、主题氛围浮尘（可一键关闭）；
  - **角色在场感**：顶部 Hero 角色状态卡直接展示她“此刻在哪、正在做什么、心情与精力条、刚冒出来的念头”，像推开净善宫的窗看一眼她今天过得怎么样，而不是冰冷的“服务器监控面板”；
  - **温差排版**：系统控制与数据用利落现代无衬线 + 等宽对齐数字；**她写的日记、心事、歌词、对话原文**使用温润的衬线/楷体（霞鹜文楷），一眼分清“系统事实”和“她的声音”。
- **坚决消灭“AI 模板味”**：
  - 禁用高饱和蓝紫霓虹渐变、禁用满屏重投影毛玻璃套娃、禁用无意义的发光边框；
  - 留白充足（卡片内边距 ≥ 20px、区块间距 16–24px），信息层级靠字重、色阶和间距拉开，不靠花哨装饰线。

## 2. 前端技术栈（`zySoulbot/web/`）

| 能力 | 选型 | 说明 |
|---|---|---|
| 构建与框架 | **Vite 6 + React 19 + TypeScript** | 开发秒级热更；`vite build` 产出静态目录由后端 Hono 单进程托管 |
| 样式体系 | **Tailwind CSS v4** | CSS 变量驱动多主题实时切换，零运行时 CSS-in-JS 开销 |
| 组件原语 | **shadcn/ui（Radix UI）** | 完整键盘可访问性与焦点环，所有组件源码归本地、按本规范定制圆角与边框 |
| 微交互动效 | **Motion (`motion/react`)** | 物理弹簧动画（滑块切换、卡片进入、抽屉展开、歌单波形），尊重 `prefers-reduced-motion` |
| 轻提示 & 抽屉 | **Sonner + Vaul** | 右下角精致 Toast 与顺滑侧边详情抽屉 |
| 图标 & 图表 | **Lucide React + Recharts** | 1.75px 统一线宽图标；柔和渐变面积图画 PAD 情绪/精力曲线与 Token 消耗账本 |

## 3. 色彩系统（三套日间二次元主题 + 星夜模式）

每套主题严格对齐 6 层语义令牌（避免混用裸色值），保证正文对比度 ≥ 4.5:1：

### 3.1 须弥薄荷（`mint` — 纳西妲默认推荐）
| 语义 | 色值 | 用途 |
|---|---|---|
| `--bg` | `#F3FBF6` | 画布底色（极淡草露绿） |
| `--surface` | `#FFFFFF` | 主卡片表面 |
| `--surface-2` | `#EAF6EE` | 次级胶囊、输入框、悬浮底 |
| `--border` | `#D3EAD9` | 1px 细腻描边 |
| `--text` / `--text-2` | `#1C3828` / `#557563` | 主正文 / 辅助说明 |
| `--accent` / `--accent-soft` | `#26A678` / `#DAF3E6` | 主操作、活跃导航、高亮胶囊 |
| `--grad-a` → `--grad-b` | `#9CE4C2` → `#E4F7C5` | 仅用于 Hero 角色卡与品牌徽记的柔和过渡 |

### 3.2 晴空天蓝（`sky`）
- `--bg: #F3F9FF` · `--surface: #FFFFFF` · `--surface-2: #EBF4FE` · `--border: #D4E6F8`

- `--grad-a: #A2D2F7` → `--grad-b: #CBF0FA`

### 3.3 樱花桃粉（`sakura`）
- `--bg: #FFF7F9` · `--surface: #FFFFFF` · `--surface-2: #FFEFF4` · `--border: #F5DAE3`
- `--text: #462833` · `--text-2: #87636F` · `--accent: #E35B8B` · `--accent-soft: #FCE1EB`

### 3.4 星夜深色（`night` — 夜间护眼）

## 4. 字体与排版层级

- **界面无衬线**：`'Satoshi', 'Inter', 'PingFang SC', 'Noto Sans SC', 'Microsoft YaHei', sans-serif`
- **她的手写/心声字体**：`'LXGW WenKai', 'Noto Serif SC', serif`（用于日记正文、此刻思绪、歌词、心事引言）
- **等宽数字与代码**：`'JetBrains Mono', ui-monospace, SFMono-Regular, monospace` + 全站数据开启 `font-variant-numeric: tabular-nums`
- **字号规范**：
  - 页面主标题：`22px / 700`（tight tracking `-0.02em`）
  - 区块标题：`15px / 600`
  - 正文：`14px / 1.65`；表单输入移动端保证 `≥ 16px` 防 iOS 缩放
  - 胶囊/元信息标签：`12px / 500`

## 5. 信息架构（清爽 6 大视图，告别碎片化菜单）

左侧固定轻量导航栏（宽 `224px`，移动端滑出抽屉），围绕“了解她”而不是“堆配置表”组织：

1. **今日概览（Home）**
   - **角色 Hero 卡**：二次元立绘/头像框 + 此刻所在地点与正在做的事 + 她的实时内心独白（霞鹜文楷）+ 精力条 / 心情气象徽章；
   - **四格关键指标**：今日对话轮次、活跃心事/欲望、今日 Token 消耗 & 缓存命中率、待办审批/凭证红点；
   - **近期动态流**：把聊天、活动、新记忆、唱歌作品、自造技能按时间轴串联展示。
2. **内心与生活（Inner Life）**
   - **身心曲线**：Recharts 柔和双线图（近 48h 情绪 PAD + 精力/睡眠债节律）+ 持久化情绪来由列表；
   - **心事与欲望板**：清晰呈现每条欲望的阶段标签（萌芽 / 探索中 / 等凭证 / 等批准 / 已实现）、来源（对话/自发联想/日记）与一键干预；
   - **她的日记本**：书页式双栏阅读器，左侧日期索引，右侧霞鹜文楷全文。
3. **记忆与关系（Memory & People）**
   - **人物卡片网格**：每人展示称呼、相处阶段徽章、三轴关系细条（信任/亲密/好感）、上次联系时间、以及 **2–3 条共同故事**；
   - **记忆检索池**：支持 FTS5 全文搜索，标明留存档位（闪念/一阵/很久/永久）、敏感度、清晰度进度条，支持纠错删除；
   - **对话回放**：仿 QQ 聊天气泡还原私聊与群聊现场（含图片、表情包、语音与折叠的工具行动胶囊）。
4. **声音与作品（Expression & Works）**
   - **歌单与作品播放器**：内嵌精致二次元音频播放器（专辑封面/波形微动效/滚动歌词/当时的心情笔记），管理 Mureka 唱歌作品；
   - **表情包图库**：网格预览 + 情绪标签筛选 + 拖拽上传自动打标；
   - **语音表达**：TTS 试听、语速与柔和度调节。
5. **灵魂与能力（Soul & Abilities）**
   - **人设包工作台**：分标签页在线编辑 `identity / origin / examples / discipline / scenario / worldview / activities`，修改即时生效；
   - **本领与工作区**：已学会的 Skill 清单（直接查看 `SKILL.md`）、启用/停用、外部 MCP 工具状态；
   - **外部凭证 & 审批**：动态表单填写她登记的外部服务 API Key（密文遮罩）+ 待审批事项一键点头。
6. **账本与诊断（Usage & System）**
   - **Token 账本面板**：今日/7日花费、**Prefix Cache 命中率大字看板**、按场景（聊天/工具/抽取/生活/造能力）分布柱图、每日自主预算滑块；
   - **实时 Trace 检视器**：按 `traceId` 折叠查看完整回合（输入块体积、工具调用步骤、耗时、降级告警）；
   - **连接与安全**：模型配置、NapCat 连接状态、一键安全清空单 bot 记忆（清晰列出清空范围）。

## 6. 交互与动效硬规范（Vercel Guidelines + Emil Kowalski 准则）

- **弹簧参数统一**：
  - 主题滑块 / Tab 指示器：`{ type: 'spring', stiffness: 420, damping: 32 }`（跟手不晃）；
  - 卡片入场 / 抽屉弹出：`{ type: 'spring', stiffness: 320, damping: 28 }`，延迟错峰 ≤ 30ms；
- **严禁 `transition: all`**：只对 `transform`, `opacity`, `background-color`, `border-color` 做过渡；
- **圆角阶梯**：大卡片 `18px`、普通卡片 `14px`、按钮/输入框 `10px`、胶囊标签 `9999px`；
- **无障碍与细节**：所有图标按钮带 `aria-label` 与 Tooltip，支持键盘 Tab 焦点环，长任务（唱歌生成/人设辅助/技能测试）展示明确骨架屏与实时状态胶囊，绝不假死白屏。
